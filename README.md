# 🎫 2. osTicket Installation and Setup

### Objective

Install and configure the operating system required for the help desk environment.

### Steps

1. Booted the VM from the installation media.
2. Installed the operating system.
3. Created the administrator account.
4. Configured the computer name.
5. Configured network settings.
6. Completed the installation and restarted the system.
